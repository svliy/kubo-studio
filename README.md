# Local 网页与 Git 工作台

左侧显示 `preview.html` 网页，右侧读取当前仓库的真实 Git 工作区、暂存区、分支和最近 20 条提交。无需安装依赖，要求 Node.js 20+ 和 Git。

```powershell
npm.cmd start
```

打开 http://127.0.0.1:5173 。端口可通过 `PORT` 环境变量设置。

- 切换查看工作区、暂存区和提交记录。
- Git 状态每 5 秒自动刷新；也可以手动刷新。
- 切换桌面/手机预览。
- 修改 `preview.html` 后点击左侧刷新按钮。直接双击 HTML 无法读取 Git，请通过本地服务打开。
- 页面只读取 Git，不执行暂存、提交或切换分支。需要时在终端使用 `git add` 和 `git commit`，界面会自动更新。

服务只监听 `127.0.0.1`，仅提供明确列出的网页文件，不提供整个仓库的静态目录。
