# Local 网页与 Git 工作台

左侧显示 `preview.html` 网页，右侧显示真实 Git 工作区、暂存区与所有分支最近 60 条提交的关系图。无需安装依赖，要求 Node.js 20+ 和 Git。

```powershell
npm.cmd start
```

打开 http://127.0.0.1:5173 。端口可通过 `PORT` 环境变量设置。

- 切换查看工作区、暂存区和提交记录。
- 提交图按真实父提交连线，显示分支标签和当前 HEAD；包括尚未合入主分支的提交。
- 点击提交查看作者、时间、提交信息及改动文件。合并提交相对第一个父提交展示差异，初始提交显示新增文件。
- 点击“预览这个版本”，左侧展示该提交保存的 `preview.html`，点击“返回工作区”恢复实时预览。预览不会切换 Git 分支或改动工作区。
- Git 状态每 5 秒自动刷新；也可以手动刷新。
- 切换桌面/手机预览。
- 修改 `preview.html` 后点击左侧刷新按钮。直接双击 HTML 无法读取 Git，请通过本地服务打开。
- 页面只读取 Git，不执行暂存、提交或切换分支。需要时在终端使用 `git add` 和 `git commit`，界面会自动更新。

服务只监听 `127.0.0.1`，仅提供明确列出的网页文件，不提供整个仓库的静态目录。

历史版本目前支持项目中的独立 HTML 页面 `preview.html`；历史页面脚本在隔离的 iframe 中运行，不能访问工作台或其本地存储。
